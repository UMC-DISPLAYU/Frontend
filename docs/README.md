- DisplayContent의 view는 전시 작업 화면의 전시 콘텐츠 탭 · 섹션 화면 열람이다. 일반 팀원은 전시작 탭만 보고, 전시 콘텐츠는 전시 미리보기에서만 본다.
- 전시 관리자는 전시 대표자가 관리자(MANAGER)로 지정한 팀원이다. 전시 작업에서는 대표자와 같이 전체 작품 수정 · 삭제, 다른 작가 대신 등록(Artwork proxy), 순서 편집, 전시 콘텐츠 관리를 할 수 있다.
