# 반응형 · 인터랙션 정책

프론트엔드 개발자를 위한 반응형 · 인터랙션 정책이다. (2026-11-05 정리)

1. 아래에 없는 세부 정책은 [프로토타입](https://displayu-demo.vercel.app/)을 참고한다.
2. 언급되지 않았거나 정책과 맞지 않는 케이스는 개발자 판단에 맡긴다.
3. 정책 추가 · 수정이 필요하면 개발자가 이 문서(GitBook)를 직접 수정한다.

## 반응형 · 뷰포트 정책

### 브레이크포인트

| 구분     | 너비          |
| -------- | ------------- |
| 모바일   | ~ 767px       |
| 태블릿   | 768px ~ 899px |
| 데스크톱 | 900px ~       |

태블릿 전용 디자인은 따로 만들지 않는다. 768 ~ 899px 구간은 데스크톱 레이아웃을 따른다.

### 컨테이너 동작

> 화면이 넓어질 때 끝까지 늘어나는지, 최대 너비에서 가운데 정렬되는지

좌우 여백

| 구분     | 여백 |
| -------- | ---- |
| 모바일   | 20px |
| 태블릿   | 32px |
| 데스크톱 | 40px |

- 모바일: 전체 폭
- 태블릿 · 데스크톱: 최대 너비에서 가운데 정렬
  - 입력 화면(등록, 수정): 최대 672px
  - 목록, 관리 화면: 최대 1160px
  - 홈: 프로토타입을 따른다

### 최소 지원 너비

320px

### viewport meta 설정

- `width=device-width, initial-scale=1, viewport-fit=cover` (현재 설정 유지)
- 확대는 막지 않는다 (접근성)
- 입력창 자동 확대는 기존 input `16px` 규칙(`src/styles/index.css`)으로 막는다

### Safe area

| 위치 | 적용 대상                                       | 값                       |
| ---- | ----------------------------------------------- | ------------------------ |
| 상단 | 헤더                                            | `safe-area-inset-top`    |
| 하단 | 냅바(하단 내비게이션), 하단 고정 버튼, 바텀시트 | `safe-area-inset-bottom` |

Android와 iOS 모두 같은 코드(`env(safe-area-inset-*)`)로 처리되므로 OS가 아니라 위치 기준으로 나눈다.

### Mobile 100vh Bug

- `100vh` 대신 `dvh`를 사용한다 (현재 코드의 `min-h-dvh` 유지)
- 참고: [모바일 브라우저에서 100vh 적용 오류 해결 (iOS/Android)](https://velog.io/@edie_ko/Tip-%EB%AA%A8%EB%B0%94%EC%9D%BC-%EB%B8%8C%EB%9D%BC%EC%9A%B0%EC%A0%80%EC%97%90%EC%84%9C-100vh-%EC%A0%81%EC%9A%A9-%EC%98%A4%EB%A5%98-%ED%95%B4%EA%B2%B0-iosandroid)

### 가상 키보드 대응

> 입력창 포커스 시 키보드가 레이아웃을 밀어올리는 방식

| OS      | 기본 동작                                                  |
| ------- | ---------------------------------------------------------- |
| Android | 키보드가 화면 위를 덮음                                    |
| iOS     | 키보드가 화면을 덮고, 입력창이 보이도록 페이지를 밀어 올림 |

- 입력창이 키보드에 가려지지 않게 한다
- 하단 고정 버튼은 키보드 위에 붙어서 따라오게 한다
- 참고: [웹뷰 Fixed 가상 키보드 VisualViewport 사용](https://velog.io/@th_velog/%EC%9B%B9%EB%B7%B0-Fixed-%EA%B0%80%EC%83%81-%ED%82%A4%EB%B3%B4%EB%93%9C-VisualViewport-%EC%82%AC%EC%9A%A9)

### 터치 영역

> 아이콘 크기와 상관없이 클릭 가능한 요소

- 44 × 44px 이상 보장

### 스크롤 바운스

| 구분 | 적용 대상                |
| ---- | ------------------------ |
| 허용 | 기본값                   |
| 막기 | 오버레이 팝업 내부, 지도 |

### sticky hover 문제

- 모바일에서는 hover 효과를 적용하지 않는다

## 인터랙션 정책

### 모션 토큰

> 애니메이션 시간과 가속 곡선을 몇 가지로 정해 통일

| 이름 | 시간  | 사용처                      |
| ---- | ----- | --------------------------- |
| fast | 200ms | 색 변화, 버튼 누름, 호버    |
| base | 300ms | 시트 · 모달 열림, 토스트    |
| slow | 450ms | 화면 진입, 큰 레이아웃 변화 |

### 가속 곡선

`cubic-bezier(.16, 1, .3, 1)`

### 클릭 가능한 요소의 상태

| 상태   | 모습                                                                 |
| ------ | -------------------------------------------------------------------- |
| 기본   | -                                                                    |
| 호버   | 마우스 기기에서만. 배경 한 단계 진하게. 이미지는 호버 시 이미지 확대 |
| 누름   | 살짝 작아짐 (`scale(.99)`)                                           |
| 포커스 | 키보드 이동 시에만 테두리 2px (`focus-visible`)                      |
| 비활성 | 배경 `bg-secondary`, 글자 `text-disable`, 커서 기본                  |

### 오버레이

| 구분     | 형태                                        |
| -------- | ------------------------------------------- |
| 모바일   | 바텀시트 (하단 고정, 위쪽만 둥글게, 손잡이) |
| 태블릿   | 가운데 모달                                 |
| 데스크톱 | 가운데 모달                                 |

- 열리면 뒤 페이지 스크롤을 잠근다
- 시트 안을 끝까지 스크롤해도 뒤 페이지는 스크롤되지 않는다
- 닫는 방법: 배경 탭, ESC, **뒤로가기 (페이지 이동 대신 오버레이만 닫기)**

### 토스트

- 위치: 하단 가운데, 냅바 위
- 노출 시간: 3초

### 화면 진입

- 페이지 이동 시 스크롤을 최상단으로 올린다 (뒤로가기 제외)
- 요소 등장 애니메이션
  - 적용 대상: 목록 아이템
  - 헤더, 냅바, 버튼, 텍스트 등 고정 UI에는 적용하지 않는다
  - 아래에서 12px 올라오며 나타나고, 카드마다 60ms씩 순서대로 등장한다

### 레이아웃 쉬프트 (미확정)

- **사용처: 스켈레톤 사용이 어색한 곳 (개발자 판단)**
- 불러오는 중인 영역은 실제 콘텐츠 크기만큼 자리를 미리 차지한다
- 이미지는 비율을 고정해서, 불러온 뒤 높이가 바뀌지 않게 한다

### 이미지 로딩

- **스켈레톤 적용 (카드 단위)**
- 모양: 실제 콘텐츠와 같은 크기 · 위치 · 모서리
- 움직임: shimmer
- 이미지 로딩이 완료되면 **fade-in**
- 실패 시 기존 에러 표시를 사용한다

### 뒤로가기

- 이전 스크롤 위치를 복원한다
- 뒤로가기는 페이지 단위로 동작한다 (탭 · 필터 변경은 뒤로가기 단계로 치지 않음)
- 오버레이가 열린 상태면 오버레이를 닫는다

### 영상 재생

- 목록 · 카드는 썸네일만, 홈은 대표 포스터만 자동 재생한다
- 자동 재생은 무음, 사용자가 조작하면 소리를 낸다

### hover zoom

- 작품 · 전시 카드: 카드 안 이미지가 3~4% 확대 (테두리를 넘지 않음)
- 화살표 밀림: 화살표가 진행 방향으로 2~3px 이동 (뒤로가기는 반대 방향)
- 모바일에서는 적용하지 않는다
